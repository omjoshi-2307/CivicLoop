# CivicLoop

**Complaints That Don't Disappear**

A citizen-centric civic grievance platform for transparent complaint tracking, duplicate issue clustering, and evidence-based public accountability.

## Contributing

Read [CONTRIBUTING.md](CONTRIBUTING.md) before making changes. Work on a focused feature branch and open a pull request for review. Keep main stable.

## Project status

This repository currently contains planning and contributor documentation plus the initial directory placeholders. The application implementation has not been initialized. Technology choices described in the decision log are approved baselines, while hosting, production file storage and some implementation details remain undecided.
