# CivicLoop — Glossary

| Term | Meaning in CivicLoop |
|---|---|
| API | Interface through which the frontend and backend exchange requests and responses. |
| Authentication | Verifying who a user is. |
| Authorization | Deciding what an authenticated user is allowed to do. |
| RBAC | Role-Based Access Control; permissions assigned according to roles. |
| Citizen | User who submits and tracks civic complaints. |
| Authority | Authorized official who reviews and updates complaints within an assigned scope. |
| Administrator | User who manages authority access and platform configuration. |
| Complaint | A citizen-submitted civic issue record with a tracking ID. |
| Tracking ID | Identifier used to refer to a complaint; it does not replace access control. |
| Status timeline | Chronological history of complaint status changes and public updates. |
| Duplicate suggestion | A possible relationship between similar complaints, requiring authority review. |
| Complaint group | A manually confirmed relationship among complaint records; original records remain intact. |
| Evidence | An uploaded file or supporting record associated with a complaint or resolution. |
| Public visibility | Fields explicitly approved for display to unauthenticated visitors. |
| Ward | Geographic administrative area used for authority scope and analytics. |
| Escalation | An authorized action to raise an overdue complaint for further attention. |
| ORM | Object-Relational Mapper; a tool for accessing relational databases from application code. |
| Migration | Versioned database schema change applied in a controlled sequence. |
| Session | Server-managed state representing an authenticated browser login. |
| Modular monolith | One deployable backend organized into separate internal modules. |
| MVP | Minimum Viable Product; the smallest agreed product scope for the demonstration. |
| Synthetic data | Artificial test data that does not represent real citizens or complaints. |
| Lockfile | File recording resolved package versions for reproducible dependency installation. |
| Pull request | Proposed code change submitted for review before merging. |
